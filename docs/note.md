# 会場までの道案内 作成アプリ — 企画メモ

## 1. 概要

### 1.1 困っている人

#### 道案内を作る人（作成者）
- 看板を立てたり、目的地までの途中に人を立たせたりするのは面倒
- 一方で、Google Map 等のリンクだけを渡すのも味気ない（？）

#### その会場に行きたい人（参加者）
- 「駅 → 会場」の道のりなので、もっとシンプルに案内してほしい
- 看板等が実際に見えているような、直感的な移動がしたい

### 1.2 解決したいこと

| 立場 | 解決したいこと |
|---|---|
| 作成者 | 中継点（駅など）から **1回道を歩くだけ** で、目印・曲がり角などの簡単な道案内を作れる |
| 参加者 | 目印・曲がる方角だけを **画面に単純に表示** してくれればよい |

### 1.3 何が欲しいか

#### 作成者
- **操作をどれだけ省略できるか** を最重視
- 自分でその地点の写真を撮る → そのままバックエンドで交差点同士をつなぐ
- どこを目印にするか・どこを曲がるかはすべてバックエンドが出してくれる
  - 実際に撮った写真 + どこに曲がるか
- 作成者が撮るのは **Street View 等では分かりにくい、ややこしいポイントだけ**
  - → それらを通る経路を計算し、他の交差点等の目印は Google Street View（+ VLM で目印抽出）で補完
- 写真撮影時点の位置情報 → 目印になる交差点・位置を教えてくれる
- VLM で「何を目印にすればいいか」等を抽出

#### 参加者
- （同様に）操作を省略したい
- 各写真の場所 → 次にどこをどう曲がるかだけを教えてくれる
- 会場に行くまでの **最低限** だけでよい（付随情報は不要）

### 1.4 あればうれしい機能
- 他の誰かが作ったデータを溜めておく（人気の場所をキャッシュ）
  - 誰かのデータを流用できるはず
- 最小限の動作に加えて、画像を順に表示していく
  - あとどのくらい直進か
  - その画像の場所に着いたらどちらに行くか
  - 間違っていたら教えてくれる 等
- どこで迷ったか等の統計（バックエンド）

---

## 2. 必要なコンポーネント

### 2.1 作成者側
1. マップ作成者が、ややこしい箇所・その目印・どこに入るか等を **先に写真に撮る + 位置情報を取得**
   - 疑問: 取得した写真から位置情報は取れるのか？（EXIF 等）
2. 「移動元 → 移動先」を入力として、上記の地点を **すべて通る経路** を算出
3. 各交差点について Street View の写真を切り出す
   - ① VLM 等に入力して目印を出してもらう
   - ② 曲がる方向を計算し、描画
4. 各写真を連結して **道の計画（写真列）** を出力
5. 道の計画を URL 等で公開

### 2.2 参加者側
1. 道の計画を表示
2. 写真列を表示（目印の写真・右左折・どの程度の距離か）
   - 注: 距離表示をすると毎回計算が必要になりそう
3. 通り過ぎの検知くらいは入れてもよい
